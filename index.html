A tiny navigation helper

SatisPalette

Simplifying navigation, one search at a time.

The story

Finding the right page on a website can take more clicks than it should. SatisPalette is a small, straightforward command palette that helps visitors search indexed pages and jump where they need to go.

Get a copy

Download or clone the project from GitHub. Add widget.js and your search.json index to your site.

Get SatisPalette on GitHub

Set it up

Configure the path to your search index before loading the widget. Then press Ctrl + K to search your pages.

<script>
  window.CommandPaletteConfig = { data: "./search.json" };
</script>
<script src="widget.js"></script>
